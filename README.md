# 🐶 Pug Paradise

Welcome to **Pug Paradise** - your ultimate destination for pug-themed games, hacks, chatrooms, and more!

## Features

### Current Features
- **Pug-Themed Homepage**: Beautiful, textured design with pug-inspired color palette
- **Interactive Elements**:
  - Animated paw prints background
  - Hover effects and animations
  - Click on the ASCII pug for a surprise!
  - Paw print trail follows your mouse
  - Floating emoji effects
  - Auto-rotating pug facts
  - Interactive notifications

### Coming Soon
- 🎮 **Games**: Pug-tastic games for all ages
- 💻 **Hacks**: Cool coding tricks and tools
- 💬 **Chatroom**: Connect with fellow pug enthusiasts
- 📸 **Gallery**: Share and browse pug photos

## Technologies Used
- HTML5
- CSS3 (with advanced animations and gradients)
- Vanilla JavaScript (no frameworks needed!)

## Installation

Simply open `index.html` in your web browser to view the site!

For local development:
```bash
# Clone the repository
git clone <repository-url>

# Navigate to the directory
cd THE_PUG_SITE

# Open in browser
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```
